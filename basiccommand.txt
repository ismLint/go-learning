1) go mod init <name> - init new go.mod
2) go mod tidy - подтягивает недостоющие библиотеки из go.mod удаляет не нужные (no use)
3) go run (or go run ./go-basics or go run main.go) - компиляция во временную директорию и сразу же запуск
4) go build - компилирует в бинарный файл 
5) go install - компилирует бинарник и помещает его в системную папку $GOPATH/bin
6) go fmt ./... - форматирование кода по стандарту gofmt
7) go vet ./... - втроенный статический анализатор кода (находит потенциальные баги)
8) go test ./... - запускает все тесты в проекте (файлы с суффиксом _test.go)
9) go test -v ./go-basics - запускает все тесты в конкретной директории.
